# Live agent evaluations

These are dated records of the live agent evaluation rounds. In each round, independent coding
agents got the docs, the `peeky` command and a new bug, without Peeky's source.

Each report describes Peeky as it was on its date: its commands, output, limits and findings. Many
of those findings were fixed later. For Peeky as it is now, read the
[AGENT_GUIDE](../AGENT_GUIDE.md), the [COOKBOOK](../COOKBOOK.md) and the
[CHANGELOG](../../CHANGELOG.md).

[HISTORY.md](../HISTORY.md#live-agent-evaluations) lists the reports in order.
